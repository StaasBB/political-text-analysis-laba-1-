texts/raw

Исходные тексты до автоматической обработки.


texts/clean

Очищенные версии текстов. Сюда записывает результаты build_corpus.py.

Исходные файлы в raw скрипт не изменяет.





authors.csv

Таблица с метаданными произведений:

Поле	Значение
text_id	Уникальный идентификатор текста
author	Автор
quadrant	Предварительно заданный квадрант
work	Название произведения
genre	Жанр
style	Описательная характеристика текста

quadrant используется как целевая категория при классификации, а не как стилометрический признак.




Обработка текстов

В исходном корпусе принято правило:

одна непустая строка = один абзац.

Скрипт очистки:

удаляет технические конструкции в [] и {};
удаляет круглые скобки вместе с содержимым, если внутри встречается стр или стр.;
сохраняет остальные круглые скобки;
удаляет технические разделители вроде * * *;
убирает лишние пробелы;
сохраняет исходные слова, орфографию и пунктуацию;
сохраняет структуру абзацев.
