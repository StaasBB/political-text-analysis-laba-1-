corpus_stats.txt
статистика для презентации
-------



Обработка текстов

В исходном корпусе принято правило:

одна непустая строка = один абзац.

Скрипт очистки:

удаляет технические конструкции в [] и {};
удаляет круглые скобки вместе с содержимым, если внутри встречается стр или стр.;
сохраняет остальные круглые скобки;
удаляет технические разделители вроде * * *;
убирает лишние пробелы;
сохраняет исходные слова, орфографию и пунктуацию;
сохраняет структуру абзацев.
